# SurveyLens add-on: protocol record

## Pre-commitment (written 2026-10-01, before any generation or judging)
Agreed with the user ("按你的建议来"):
1. The SurveyLens results are reported in the technical report whatever they show.
2. Same-generator baselines (NaiveRAG-Own, NaiveRAG-Pool) are run alongside Skill-Full, so that any difference
   can be attributed to the skill rather than to deepseek-v4.1-flash.
3. All 100 evaluated topics (10 disciplines x 10). The queue runs 2 topics per discipline first; the pipeline is
   checked end to end on those 20 before the remaining 80 are judged.
4. Primary metric: the released generic-rubric evaluation (scripts/evaluation/eval_ablation.py), which needs no
   unreleased files. Secondary: the discipline-aware rubric with criteria regenerated by the released
   guideline_generation scripts (the authors' criteria and BT weights are not released; stated as not identical).
   The embedding-based canonical alignment is not run (no embedding model on the gateway; model unspecified).
5. Judges: the authors' configured default plus one cross judge.
6. The topic string is the canonical human survey's title, so that survey is withheld from every run (search
   filter, PreToolUse hook, post-hoc audit), as in the SurveyBench add-on.

## Setup (2026-10-01)
- Topics: 100 (discipline, topic) pairs = the short topic names given to the published ASG systems (SurveyForge
  file names); mapping to the canonical human survey in topics_map.json (93 high-confidence, 4 medium-high,
  2 by elimination, 1 conflict resolved in favour of flagged_cases_minimal.csv; see evidence fields). Gemini/Qwen
  were prompted with the full human title instead; we follow the ASG systems.

  runs/deepseek-v4.1-flash_full_sl/slNNN; jobs sl.jobs (2 per discipline first), 6 parallel; started 2026-10-01.
  gen.sh now deletes extracted full-text images after a session (disk), keeping text, evidence, ledger, stream.

  match for 98, two fixed by hand after PDF-ligature typos (sl033, sl035); sl011 has no DOI (title only).
  sl077: the SurveyLens human file named "Non-Hermitian Topological Phenomena- A Review" contains the
  "Dipolar physics" review; both are withheld. Filter + hook upgraded to accept surveys without arXiv id and
  several title variants; smoke-tested (search filter excluded_reference=1; hook blocks the DOI URL).
- Baselines: NaiveRAG-Own started locally at launch; NaiveRAG-Pool after the skill runs.
- Judges: qwen/qwen3-30b-a3b is not served by the gateway; the closest, qwen/qwen3-30b-a3b-instruct-2507

  files (current code stores the bare title; the reference rubric reads `text`).
- Known dataset issues (from the code audit): AutoSurvey2/Biology duplicates AutoSurvey2/Business (excluded);
  Qwen uses lowercase discipline folders; SciSage has no Engineering; several systems have < 10 surveys per

  `reference` vs `references` key, Biology missing from discipline lists).
